## Overview

This project demonstrates **AI-driven meta-software development**: using a Large Language Model (GPT-5.2 via apifree.ai) to generate every artifact across the full Software Development Lifecycle (SDLC), from requirements through to deployment.

**Business Problem:** *"Our company needs a website that generates a custom horror story and a matching image based on a location entered by the user."*

**Delivered Product:** A Flask web application where users type a location (e.g., a city or landmark) and receive an AI-generated horror story paired with an AI-generated atmospheric image.

### What Makes This "Meta"?

Instead of writing code manually, the **Jupyter notebook** ([2471742CW.ipynb](Task1/2471742CW.ipynb)) prompts an LLM at each SDLC phase. The AI produces:

| Phase | Artifact | Generated By |
|-------|----------|---------------|
| **1 — Requirements** | Problem statement | `openai/gpt-5.2` |
| | 3 User personas | `openai/gpt-5.2` |
| | Product Requirements Document (PRD) | `openai/gpt-5.2` |
| | 5 User stories (JSON) | `openai/gpt-5.2` |
| **2 — Construction** | UML Use Case Diagram (PlantUML) | `openai/gpt-5.2` |
| | Flask API backend (11 endpoints) | `openai/gpt-5.2` |
| | Bootstrap 5 frontend (HTML) | `openai/gpt-5.2` |
| | AI banner image | `qwen/qwen-image-2512` |
| | Unit tests (pytest) | `openai/gpt-5.2` |
| | README & requirements.txt | `openai/gpt-5.2` |
| **3 — CI/CD & Deploy** | Dockerfile & .dockerignore | `openai/gpt-5.2` |
| | GitHub Actions workflow | `openai/gpt-5.2` |

## API Key Configuration (`.env` Files)

This project requires an API key from [apifree.ai](https://apifree.ai) (free tier works). **There are two `.env` files**, each serving a different entry point:

### `.env` #1 — `Task1/.env`

| | |
|---|---|
| **Used by** | The Jupyter notebook ([2471742CW.ipynb](Task1/2471742CW.ipynb)) |
| **Loaded by** | `utils.py` → `load_environment()` (walks up directory tree to find it) |
| **Purpose** | Powers all LLM calls in the notebook — generating personas, PRD, user stories, UML diagrams, Flask code, HTML, tests, Dockerfile, and CI/CD config |
| **Created by** | **You**, manually |

```
APIFREE_API_KEY=your_api_key_here
```

### `.env` #2 — `Task1/artifacts/app/flask/.env`

| | |
|---|---|
| **Used by** | The Flask web application ([main.py](Task1/artifacts/app/flask/main.py)) |
| **Loaded by** | `main.py` → `load_dotenv()` (loads from the current working directory) |
| **Purpose** | Powers the AI image generation API calls when users click "Generate" on the website — creates horror-themed images to match each story |
| **Created by** | The notebook (automatically copied from `Task1/.env` during Phase 2.2a), **or** manually if running the Flask app standalone |

```
APIFREE_API_KEY=your_api_key_here
```

> **Note:** If you run the full notebook, `.env` #2 is created automatically — you only need to create `.env` #1. If you skip the notebook and run the Flask app directly, you must create `.env` #2 manually.

## Quick Start

### Prerequisites

- Python 3.11+
- An API key from [apifree.ai](https://apifree.ai)

---

### Option 1: Run the Full AI-Driven SDLC (Jupyter Notebook)

This replays the entire meta-software development process — the notebook calls the LLM live to regenerate every artifact.

```bash
# 1. Install Jupyter and dependencies
pip install jupyter requests Pillow python-dotenv

# 2. Create .env in Task1/ with your API key
echo "APIFREE_API_KEY=your_key" > Task1/.env

# 3. Navigate to Task1 and launch the notebook
cd Task1
jupyter notebook 2471742CW.ipynb
```

Run each cell in order. The notebook will:
1. Generate personas, PRD, and user stories
2. Create a UML use case diagram
3. Write the full Flask backend + HTML frontend
4. Generate an AI horror banner image
5. Produce unit tests
6. Output Docker & CI/CD configuration
7. **Automatically copy `.env` to `artifacts/app/flask/`** so the generated app is ready to run

> Some cells (especially image generation) may take 30–60 seconds due to API polling.

---

### Option 2: Run the Flask App Directly (Skip the Notebook)

If you only want to see the final product — the horror story generator website — without re-running the AI SDLC:

```bash
# 1. Go to the Flask app directory
cd Task1/artifacts/app/flask

# 2. Create .env here with your API key (required for AI image generation)
echo "APIFREE_API_KEY=your_key" > .env

# 3. Install dependencies
pip install -r requirements.txt

# 4. Start the server
python main.py
```

Open your browser and visit: **http://127.0.0.1:5005**

---

### Option 3: Run with Docker

The Docker image does not bundle `.env` (it is excluded by `.dockerignore`). At runtime, pass the API key as an environment variable:

```bash
# 1. Build the image
cd Task1/artifacts/app/flask
docker build -t horror-story-generator .

# 2. Run the container, passing the API key inline
docker run -p 5005:5005 -e APIFREE_API_KEY=your_key horror-story-generator
```

Or pull the pre-built image from GitHub Container Registry (pushed automatically by CI/CD):

```bash
docker pull ghcr.io/{owner}/horror-story-generator:latest
docker run -p 5005:5005 -e APIFREE_API_KEY=your_key ghcr.io/{owner}/horror-story-generator:latest
```

The app will be available at: **http://127.0.0.1:5005**

## API Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| `GET` | `/health` | Health check |
| `GET` | `/api/locations/suggest?q=...` | Location autocomplete suggestions |
| `POST` | `/api/generate` | Generate a horror story + image for a location |
| `GET` | `/api/presets` | Get available tone & length presets |
| `POST` | `/api/generate/custom` | Generate with custom parameters |
| `GET` | `/api/stories` | List all generated stories (history) |
| `POST` | `/api/stories/<id>/share` | Increment share count for a story |
| `POST` | `/api/stories/<id>/report` | Report inappropriate content |
| `GET` | `/mod/reports` | Moderator: view all reports |
| `POST` | `/mod/stories/<id>/action` | Moderator: hide/delete/block/regenerate |
| `GET` | `/` | Serve the interactive HTML frontend |

### Example cURL Requests

**Generate a story:**
```bash
curl -X POST http://127.0.0.1:5005/api/generate \
  -H "Content-Type: application/json" \
  -d '{"location":"abandoned lighthouse","preset":"classic"}'
```

**Get story history:**
```bash
curl http://127.0.0.1:5005/api/stories
```
